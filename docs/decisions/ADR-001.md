# ADR-001: Use a Single Logical Application Architecture

## Status
Accepted

## Context
The Hub contains request management, authorization, approval, persistence, and audit responsibilities. Current requirements do not justify distributed services.

## Decision
Use one logical application architecture with clear internal responsibility boundaries instead of microservices.

## Consequences
The initial system is simpler to build, test, reason about, and keep consistent. Independent scaling is deferred until justified by evidence.

## Revisit When
Reconsider if independent scaling, deployment, team ownership, isolation, or reliability requirements emerge.
