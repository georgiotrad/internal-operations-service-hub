# ADR-002: Use File Persistence for the Week 2 Slice

## Status
Accepted for the Week 2 teaching milestone

## Context
Week 2 requires persistence proof for one narrow lifecycle behavior. Week 1 did not select a specific database product, and the exercise explicitly avoids adding unnecessary external dependencies.

## Decision
Persist the Week 2 request slice to `backend/data/requests.json`.

## Relationship to Week 1
This does not replace the Week 1 conclusion that relational storage is a reasonable production candidate. It is a bounded implementation choice for the teaching milestone.

## Consequences
The slice can prove state survives backend restarts with no database setup. The file store is not intended as a production persistence design.

## Revisit When
Replace it when the course moves to a production-oriented storage implementation or requirements justify a database.
